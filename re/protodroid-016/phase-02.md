## 6. Limitations

There is no Android handset, ADB, GPU profiler, SimplePerf, or Perfetto session available. The external projects target different games, guest ISAs, renderers, drivers, and test settings. GoW III and ISS renderer files—and the original five focused native test files—share substantial or identical lineage and cannot be counted as independent validation; their page-state test differs only by a marker comment and uses a byte-identical `PageState` header. Several source documents explicitly describe unvalidated Android ideas, and Bloodborne's controlled results are Adreno-specific with Mali unsupported at the pinned revision. Black's glslang is stubbed, its direct concurrency probe bypasses caller memoization, and PrototypeRecomp's `pread` delay is synthetic; neither establishes real shader/rendering/loading performance. Bloodborne's pinned UMA has no clean UBSan/TSan result, AOT variants has no clean ASan/LSan result, and the unresolved TSan `mmap` model report is not a proven production race. Original `/tmp` raw artifacts are unavailable; only explicitly regenerated current evidence is cited as present. License review permits source reading here but no external code has been incorporated.
